Projects

Four data projects from my work, each described by the problem, the method, and the result.

Vendor Metadata Quality Enhancement and Data Validation

Problem
Inconsistent and inaccurate vendor metadata was causing data quality issues across enterprise systems.
What I did
Wrote SQL queries (joins, subqueries) to find inconsistent records, invalid email IDs, and missing attributes, then used advanced Excel for validation, reconciliation, and reporting.
Result
Improved vendor data accuracy and consistency, reduced downstream process errors, and strengthened data governance.
  • SQL
  • Excel

CRC-Based Document Reconciliation and Batch Processing

Problem
Documents with identical CRC values carried inconsistent vendor information, risking incorrect record linkage.
What I did
Built SQL queries with window functions, self joins, and conditional filtering to detect mismatched vendor-document links, then corrected metadata records in batches.
Result
Reduced manual work, improved data integrity, and ensured accurate record linkage across document repositories.
  • SQL window functions
  • Self joins
  • Excel

Buffer Work Monitoring and Trend Analysis Dashboard

Problem
Buffer levels fluctuated without clear visibility, which limited proactive operational planning.
What I did
Built a monitoring dashboard and carried out data cleaning, normalization, exploratory analysis, KPI tracking, and correlation analysis to find root causes.
Result
Gave management the insight to take corrective action and plan resources, helping stabilize the process and improve buffer levels.
  • Google Sheets
  • Pivot tables
  • IF functions

Vendor Master Data Optimization and Deduplication

Problem
Duplicate vendor records across enterprise databases were reducing data reliability.
What I did
Designed SQL queries and Excel automation tools to standardize vendor information, and set up document replacement and batch processing workflows.
Result
Cut processing time, improved data accuracy, and kept records compliant with governance rules through validation and reconciliation.
  • SQL
  • Excel automation
